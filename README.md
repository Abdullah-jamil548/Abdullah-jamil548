<summary>⚙️ How to enable the snake contribution animation (click to expand)</summary>

1. In your **Abdullah-jamil548/Abdullah-jamil548** profile repo, create a file: `.github/workflows/snake.yml`
2. Paste this workflow:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 0 * * *"
  push:
    branches:
      - main
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: Abdullah-jamil548
          outputs: |
            dist/github-contribution-grid-snake.svg
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Commit — then go to the **Actions** tab and run it manually once. After that it updates automatically every day.
